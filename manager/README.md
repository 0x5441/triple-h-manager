# مدير إعلانات حراج

واجهة سطح مكتب لإدارة عدة حسابات وتحديث الإعلانات ونشر إعلانات جديدة من Google Sheets.

## التشغيل

### Windows

انقر مرتين على `run_windows.bat`.

### macOS

من Terminal داخل مجلد المشروع:

```bash
chmod +x run_mac.command
./run_mac.command
```

يجب تثبيت Google Chrome وPython 3.10 أو أحدث. Selenium يثبت ChromeDriver المناسب تلقائيًا.

## الاستخدام

1. اضغط **إضافة** وأدخل اسم الحساب ورقم الجوال وكلمة المرور.
2. اختر الحساب ثم اضغط **إضافة رابط** لكل إعلان يخصه.
3. اضغط **تحديث الحساب المحدد** أو **تحديث جميع الحسابات**.
4. تابع النتيجة من سجل التشغيل أسفل الواجهة.

## نشر إعلانات من Google Sheets

1. اجعل مشاركة Google Sheet: **أي شخص لديه الرابط — مشاهد**.
2. افتح **إعدادات Google Sheets** وأدخل الرابط العام، ثم اضغط **جلب التبويبات** واختر تبويب الإعلانات.
3. يجب أن يحتوي الصف الأول على الأعمدة: `account`, `title`, `body`, `phone`, `image`, `status`.
4. ضع اسم الحساب المسجل في البرنامج داخل `account`. يمكن تركه فارغًا ليأخذ أول حساب متاح الصف.
5. اترك **تجربة بدون نشر** مفعلة أول مرة. سيملأ البرنامج النموذج ولن يضغط زر الإنشاء.
6. بعد التحقق، ألغ وضع التجربة وشغّل النشر. عند النجاح يحفظ البرنامج رقم الصف محليًا حتى لا ينشره مرة أخرى.

عمود `image` موجود للتجهيز لكنه غير مفعّل حتى يتوفر محدد HTML لحقل رفع الصور في صفحة حراج.

كل حساب يعمل داخل متصفح مستقل. إذا فشل إعلان، يستمر البرنامج في الإعلان التالي. تُحفظ صور الأخطاء في `data/errors`.

## حماية كلمات المرور

- حقل كلمة المرور مخفي داخل الواجهة.
- ملف الحسابات كاملًا محفوظ مشفرًا في `data/accounts.enc`.
- مفتاح فك التشفير موجود محليًا في `data/.secret.key` ولا ينبغي مشاركته.
- هذه الحماية تمنع قراءة كلمات المرور مباشرة من الملف، لكنها لا تحميها ممن يملك وصولًا كاملًا إلى الجهاز والملفين معًا.

## ملاحظة مهمة

النشر يعتمد على محددات `data-testid` المرسلة. حقل رقم التواصل يحاول عدة محددات شائعة، وإذا لم يجده يوقف العملية ويطلب المحدد الصحيح بدل نشر بيانات ناقصة.
